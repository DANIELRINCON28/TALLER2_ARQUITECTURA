Crear nuevo pedido (Ver patrones en acción)

Script de Demostración: ejecucion_patrones.py

Ubicación: projects/django-marketplace/ejecucion_patrones.py

Cómo ejecutarlo:

cd projects\django-marketplace
python ejecucion_patrones.py

Lo que verás:

  • Sección Builder: 3 escenarios de construcción con diferentes configuraciones
  • Sección Adapter: Integración con MotoYA, EcoBike y PaqueteriaZ
  • Sección Strategy: 3 estrategias (Standard, Eco, Cost) con diferentes casos
  • Sección Observer: Notificaciones multi-canal en acción
  • Sección Integración: FLUJO COMPLETO end-to-end usando todos los patrones

Características del script:

  • Logs detallados con formato claro
  • Pausas interactivas (presiona ENTER para continuar)
  • Explicación de beneficios de cada patrón
  • Usa datos reales de la base de datos
  • Resumen final de la integración completa

Información del Sistema

Al crear un pedido se ejecutan automáticamente:

  1. Builder: Construye el pedido paso a paso con validaciones
  2. Strategy: Selecciona el mejor proveedor según tus criterios
  3. Adapter: Se integra con la API del proveedor seleccionado
  4. Observer: Envía notificaciones automáticas a todos los canales

Verás logs detallados de:

  • Código de paquete generado
  • Peso total calculado
  • Proveedor seleccionado y razón
  • Tracking code generado
  • Notificaciones enviadas por canal (Email, SMS, Webhook, Logging)

Tip: En la página de detalle del pedido, usa los botones de "Simular Despacho/Tránsito/Entrega" para ver el patrón Observer en acción con logs en tiempo real.
